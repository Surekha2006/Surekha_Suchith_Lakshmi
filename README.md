# OPC_MiniProject
Patient scheduling optimization using FCFS, SPT, EDD, and Hybrid methods under resource constraints

This project studies how hospitals can schedule patients when resources like beds and oxygen are limited. Different methods such as FCFS, SPT, EDD, and a hybrid approach are used. We compare them using flow time, delay, and survival rate to understand which method works best in emergency situations.
